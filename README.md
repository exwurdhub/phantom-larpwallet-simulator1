**Phantom LarpWallet** is an open-source, lightweight **crypto wallet simulator** and **Web3 UI preview engine**. Designed specifically for blockchain developers, UI/UX designers, and testers, it allows you to dynamically build, customize, and display realistic cryptocurrency wallet balances inside a responsive mobile frame.

🌐 **Try the Live Hosted Version:** Explore the full interface at [LarpWallet Crypto Simulator](https://larpwallet.org).

---

## ✨ Key Features

- **📱 Realistic Mobile Viewport:** Interactive smartphone screen with Dynamic Island and modern frame design.
- **🪙 Dynamic Asset Management:** Add, edit, and update crypto token balances, custom symbols, and prices dynamically.
- **⚡ Instant Calculations:** Automated total portfolio valuation engine computed in USD.
- **🎨 Modern Glassmorphism Design:** Dark-mode responsive styling powered by raw CSS custom properties.
- **🚀 Zero Dependencies:** Built strictly with Vanilla HTML5, CSS3, and JavaScript — no Node.js, heavy frameworks, or build tools required.
